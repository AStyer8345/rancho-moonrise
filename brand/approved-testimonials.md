## How this file works

1. Claude drafts candidate entries here verbatim from captured reviews. Every candidate lands as `STATUS: UNAPPROVED`.
2. Adam (or Ashley) flips a candidate to `STATUS: APPROVED` and fills in `EVENT DATE`.
3. Only then may a content task place it on a page.

**Hard rules:**
- Never edit a guest's words. Trim with an ellipsis if needed; never rewrite or "polish."
- Never invent a reviewer name, an event date, or a quote.
- A review date is NOT an event date. Both are recorded separately below.
