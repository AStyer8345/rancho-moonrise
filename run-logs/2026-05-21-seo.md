## What I did

Added `articleSection` to the `BlogPosting` JSON-LD on each of the 17 blog cluster posts. `articleSection` is a schema.org `Article` property that engines (Google, Perplexity, ChatGPT search) use to classify posts into topical buckets. Until today, every BlogPosting block on the site lacked it.

3. Bumped `dateModified` from `2026-05-17` → `2026-05-21` (schema actually changed today).
4. Bumped corresponding sitemap.xml `<lastmod>` to `2026-05-21` for each of the 17 blog URLs.
5. Validated all 17 BlogPosting JSON-LD blocks parse via `json.loads`; all 17 have `articleSection` set and `dateModified=2026-05-21`.
