## Design decisions
- **Why `copyrightYear` + `copyrightHolder` over Person-author / nav-promotion / Hipcamp-fix**: Pre-committed in 5/25 run-log as #1 next-slot. Autonomous (no NEEDS ADAM), cluster-wide, surgical, validates cleanly. Person-author BLOCKED on byline decision; nav promotion needs Adam confirm; Hipcamp fixes need Ashley dashboard.
- **`copyrightYear: 2026`** (integer, not string) — schema.org spec uses `Number` for `copyrightYear`. Matches the integer pattern already established by `wordCount`.
- **`copyrightHolder` shape**: separate inline Organization with `name` + `url`, mirroring the existing `publisher` block. Schema.org allows the same Organization to appear in multiple properties; AI engines and Google's Rich Results test parse both inline and `@id`-referenced forms. Inline keeps the edit purely additive — no risk of breaking other agents' assumptions about the existing `publisher` block.
- **Insertion point**: after `"isAccessibleForFree": true` and before the BlogPosting block's closing `}`. Maintains the chronological enrichment order (each new property appended at the tail).
